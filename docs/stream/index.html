02Setup

Install. Pair. Stream.

The first connection establishes trust; later connections reuse the saved identity until you revoke it.

01
Install both sides

Re-sign Vamp Stream for iPhone or iPad, then install Host, Vamp Stream Host, or Assistant on the Mac.

02
Grant only needed permissions

Screen Recording enables video. Accessibility is required only when you want keyboard or pointer control.

03
Verify the pairing

Compare the displayed device identity or pairing code on both sides before approval.

04
Select a surface

Open the full display or, with Assistant, select a single app window.

04Security

Private by network and identity.

Keep every host on a trusted LAN or private Tailscale network. Never forward its ports to the public internet.

Explicit approvalA pending connection is not trusted until you verify it on the Mac.
Authenticated videoVideo and input travel only after the selected host protocol authenticates the client.
Revocable devicesRemove a saved Stream device from the host that approved it.
No public relayVamp does not require a project-operated relay or public port forwarding.
