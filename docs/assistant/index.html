01

From a question to useful work.

A conversation is the starting point. Add web research, browser actions, or a project when the task calls for them.

01

A place to think and write

Start a conversation without opening a project. Draft a document, explain an idea, or turn notes into an outline. Save generated text through the native Save panel.

02

Research with sources

Search for current information with an optional TinyFish key, read source pages, and use the built-in browser to inspect them. Ask a vision-capable provider about an image or screenshot.

03

Bring your history with you

Import Claude, Codex, and Cursor conversation history. Keep roles, tool calls, and timestamps, then search, pin, rename, and export chats from one library. Passphrase-protected task bundles let you export and import work between workspaces.

02

Your model. Your choice.

Local models and remote providers share the same workspace, so you can choose what suits each task.

MLX

Choose a model that fits your Mac

The Model Manager recommends models for your Apple Silicon chip and memory. Download or import MLX models, resume interrupted downloads, and run local inference on your Mac. GGUF models are supported through an installed llama.cpp runtime.

API

Use the provider you prefer

Connect OpenAI, Anthropic, Gemini, OpenRouter, DeepSeek, and other providers with your own keys. Custom compatible endpoints support tools such as Ollama and LM Studio. Switch models in the composer; saved keys stay in Keychain.

ID

Connect your ChatGPT account

Assistant supports account sign-in through the local Codex app-server. Available account models appear in the composer alongside local and API models, with chat continuity and stop controls. This requires a working local Codex setup and eligible account access.

Local inference runs on your Mac. Choosing a remote provider, web search, or a connected service sends the relevant requests to that service; availability and costs depend on your provider.

03

A workspace for building real software.

Code mode adds project files, commands, context, and verification when you need more than a conversation.

01

Code with project context

Open a workspace to search files, edit code, run commands, and inspect diagnostics. Workspace indexing and symbol summaries help the agent find relevant code; optional memory carries useful facts and session summaries forward.

02

Plan, review, and verify

Review a plan before work begins. Inspect proposed changes and commands in approval cards, keep Git checkpoints, and run project checks. With verification enabled, failed checks return to the agent for another pass.

03

Use your skills and tools

Connect MCP servers and discover declarative skills from your existing coding tools. Import OpenCode providers, agents, commands, and permission rules into the native workspace. JavaScript-only provider plugins may need a compatible gateway.

04

Four specialists, different jobs.

Give work to Researcher, Builder, Reviewer, or Navigator. The workflow can carry research into implementation and pass completed code to an independent reviewer.

R

Researcher

Collect source material, compare options, and turn the findings into an implementation brief.

B

Builder

Implement a change and report the files changed, execution results, and verification evidence.

V

Reviewer

Review completed work for correctness, regressions, and missing tests, with prioritized findings.

N

Navigator

Inspect a browser flow, navigate pages, and capture visible behavior for the task.

Bots have their own private browser profiles. Follow a run in the Bot Console, send a follow-up to the queue, or steer work already in progress. Optional bot computers provide separate workspaces; Linux micro-VM support requires the container runtime.

05Inside Assistant

Native tools, shown live.

Browse, inspect, build, and check the result inside Assistant. These are real captures of its Browser and Simulator panels.

Build and inspect iOS apps

Boot devices, install builds, launch apps, capture screenshots, and verify the visible result without leaving Assistant.

Agent-controlled browser

Open, inspect, navigate, and verify real web pages inside the same Assistant workspace.

SHIP

From a build to a device

Ship Center can verify and archive Apple projects, export an IPA, install on a connected iPhone or iPad, or upload an archive through Xcode. Signing and delivery use valid credentials and tooling you configure on your Mac.

API

Share your local model with other tools

Enable the local API server to use the loaded model from an OpenAI-compatible client on the same Mac. A CLI is available for headless generation and serving; the server binds to loopback.

07Security

Power with a visible boundary.

The Mac owns execution. Remote clients can request work, but workspace confinement, Keychain storage, approvals, and revocation remain local.

Owner-controlled

A remote screen is not remote permission.

Sensitive tools, clipboard, files, Mac control, and workspace mutations stay behind the Mac app’s explicit policy and permission checks.

Private pairingUse a trusted LAN or Tailscale network and revoke saved devices at any time.
Keychain secretsProvider keys, session encryption keys, and remote tokens stay in platform storage.
Workspace confinementCode tools operate only inside the project the user selected.
Approval-gated actionsWrites and commands ask by default. Approval cards show the action; configured permission rules control what can run automatically.
