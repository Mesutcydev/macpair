From Mac to hand
in three steps.

The iOS app presents the right connection path without merging the underlying host protocols.

01

Run Mini Host

Launch the macOS menu-bar companion and confirm the required Screen Recording and Accessibility permissions yourself.

02

Choose a path

Select a discovered Vamp Host or Mini Host, or enter Vamp Assistant’s private address and one-time code on port 9575.

03

Use the right surface

Stream one app window through Vamp Host or Mini Host, or control the full Assistant surface. Portrait and landscape adjust to the active stream.

Trust stays visible

Small host, strict boundary.

Mini Host does not create a public relay or silently approve access. Vamp Host and Mini Host are alternative macOS host runtimes and should not run together on the shared host ports. Vamp Assistant can run alongside either because it uses its separate private control port 9575.

Signed pairingReview the pending device and exact fingerprint before approval.
Private transportUse a trusted LAN or private Tailscale network; do not expose ports publicly.
User permissionsScreen Recording and Accessibility consent remain macOS user decisions.
Separate protocolsVamp Stream selects the correct path without weakening trust or mixing host responsibilities.

Build the pair
from source.

Both apps live in the Vamp repository. No project-owned Apple team, relay, or private credential is required to build the unsigned development artifacts.

Vamp Stream

Unsigned iOS build

Generate the standalone project, then build for a connected or generic iPhoneOS destination.

xcodegen generate --spec vampstream-project.yml
xcodebuild -project VampStream.xcodeproj -scheme VampStream \
  -configuration Release -sdk iphoneos \
  -destination 'generic/platform=iOS' \
  CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO build
Vamp Mini Host

macOS menu-bar build

Build the separate host scheme, then launch it as the lightweight pairing and permission companion.

xcodebuild -project RemoteDesktopToolApps.xcodeproj \
  -scheme VampMiniHost -configuration Release \
  CODE_SIGNING_ALLOWED=NO build
