Privacy

Private by architecture.

The Vamp product website is a static, open-source project site. It does not provide user accounts, advertising profiles, a hosted remote-access relay, or a project-operated analytics dashboard. The site may be delivered by its hosting and network providers, which can process ordinary request information such as IP address, user agent, requested path, and time for security, reliability, and delivery. Visiting links to GitHub, Google Fonts, Tailscale, or other third-party resources makes a separate request governed by that provider’s privacy terms. This page stores a theme preference and a language preference in the browser’s localStorage (`vamp-theme`, `vamp-lang`). Effective date: 22 August 2026.

Vamp applications

Vamp applications are designed for direct connections over a trusted local network or a private Tailscale network. Pairing identities, trusted-peer records, session metadata, and terminal workspace state remain on the user’s machines. The project does not operate a central account database or relay that receives remote screen, input, clipboard, file, audio, or terminal content. Raw terminal bytes are not persisted to disk by the host’s session journal; only bounded in-memory reattachment data and semantic session events are used to support reconnects.

Permissions and user control

The full Mac host can use Screen Recording and Accessibility only after the user grants those permissions in macOS System Settings. Terminal-only mode rejects display, pointer, keyboard, microphone, and file-transfer commands. New peers require visible approval, and trusted peers can be revoked later. Users choose whether to install the software, which private network carries the connection, which devices are approved, and when a host or terminal session is stopped.

Reports and changes

Support messages and security reports contain the information the sender chooses to provide and are processed only to investigate and respond. Do not include credentials, pairing secrets, private keys, or unrelated personal information. Material privacy changes will be published in the public repository and reflected on this page. Questions about this notice can be sent through the project’s contact routes.
