Contact

Talk to the project.

Vamp is an open-source project rather than a hosted service with a sales or account-support team. The best contact route depends on what you need. Public questions, reproducible bugs, documentation gaps, and feature proposals belong in the GitHub repository so other users can search the answer and participate. Before opening a report, check the installation documentation and existing issues, then include the relevant operating system, Vamp version, expected result, and a concise set of reproduction steps.

Security reports

Do not post a suspected vulnerability, pairing secret, private key, real device fingerprint, or user log in a public issue. Send security-sensitive reports to security@mesut.uk or open a private GitHub Security Advisory. Include the affected component and version, impact, reproduction steps, and any proposed mitigation. Please remove credentials and personal data from screenshots and logs.

General support and contributions

For installation help, interoperability questions, or a proposed improvement, use GitHub Issues. For a code contribution, read the contribution and security guidance, keep changes focused, and explain how the result was verified. Vamp does not offer telephone support, paid priority support, remote account recovery, or access to a user’s machine. Project maintainers will never ask you to approve an unknown pairing request or to publish a host port on the public internet.
