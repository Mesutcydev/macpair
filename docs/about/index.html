About the project

Your machines. Your network.

Vamp is an open-source remote desktop and terminal workspace for people who want to reach their own computers without handing the connection to a hosted control plane. Three kits share a trust plane: Vamp Host plus Vamp Control for the Mac screen; Vamp Terminal Host plus Vamp Terminal or Safari for eight PTYs; and Vamp Linux Host plus a browser for a Linux shell. Vamp Control and Vamp Terminal cannot attach to the Linux host.

The project is local-first by design. Mac connections travel over a trusted LAN or a private Tailscale network using signed WebRTC. Linux Host and Safari use a loopback WebSocket on port 9475, exposed privately with Tailscale Serve or Cloudflare Access. New peers use signed identities and must be visibly approved on the host. Terminal access is opt-in on Vamp Host and always on for Vamp Terminal Host, Vamp Linux Host, and Safari. Vamp does not require a product account, a project-owned relay, public port forwarding, or an App Store account.

Why Vamp exists

Remote access should feel direct and understandable. Vamp keeps the machine authoritative, makes the pairing boundary visible, and gives both people and automation a stable way to inspect status and manage persistent terminal sessions. Transport loss detaches a client without destroying its terminal work, so long-running shells and agent tasks can survive a reconnect.

Open development

Vamp is released under the Apache 2.0 license. Its source, security policy, release process, protocol tests, host applications, iOS client, Linux companion, and agent integration documentation are developed in public. The project is maintained by Mesutcydev and welcomes responsible reports and contributions through GitHub.
