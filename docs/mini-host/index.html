01 · Surface

The host you can understand at a glance.

A compact status surface for the moments that matter: is it reachable, who is asking, and what has been approved?

⌁

Pairing-first

See the host fingerprint, pending device name, and full request fingerprint in one place. Approve only after your independent comparison.

◈

Permission clarity

Mini Host never captures the display or injects pointer and keyboard events. Its permission panel makes that boundary explicit.

↻

Always available

It starts its signed host runtime at launch, stays out of the Dock, and gives you Start, Stop, and Restart without opening a dashboard.

02 · Security

A small UI with the full trust boundary.

The app is separate; the security model is familiar. It reuses Vamp’s signed discovery, authenticated data channel, and explicit host approval flow.

01
Discover privately

Bonjour discovery and host signaling stay on your LAN or private tailnet. No hosted relay and no public port forwarding.

02
Inspect the request

The popover shows the device name and complete fingerprint. A new request remains pending until you act.

03
Confirm before approval

The Approve action is locked until the displayed fingerprint is entered exactly, preserving an out-of-band verification step.

Run one macOS host at a time.

Vamp Mini Host is its own product and its own trust store, but it still shares the host signaling ports with Vamp Host and Vamp Terminal Host. Stop the other Mac host before starting this one.

Mini Host is terminal-safe/view-only. It does not grant screen sharing or remote input permissions.

03 · Build

Build the separate app from source.

The Xcode project includes a dedicated VampMiniHost scheme and bundle. No Apple team or private credential is committed.

Release build

Build the menu-bar app without signing, then re-sign it for your Mac distribution workflow if needed.

xcodebuild -project RemoteDesktopToolApps.xcodeproj \
  -scheme VampMiniHost \
  -configuration Release \
  CODE_SIGNING_ALLOWED=NO build

What ships

Bundle: com.mesutcy.remotedesktop.minhost

URL scheme: vampminihost://

Storage: a dedicated Vamp Mini Host identity and trusted-peer directory under Application Support.

Surface: one menu-bar popover with pairing, approved devices, permissions, Tailscale, and runtime controls.
