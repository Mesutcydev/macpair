02macOS permissions

Two permissions, two clear jobs.

Grant permissions in System Settings to Vamp Stream Host itself. The host reports readiness but never bypasses consent.

SCREEN RECORDING

Required for video.

Without Screen Recording, Stream cannot receive the Mac display. Restart Vamp Stream Host after changing this permission if macOS asks.

ACCESSIBILITY

Required for control.

Viewing can remain available without input. Keyboard and pointer control require explicit Accessibility permission for Vamp Stream Host.

03Security

Small app, complete trust boundary.

Vamp Stream Host keeps its own identity and trusted-peer store. It does not inherit approval from Vamp Host.

Important runtime limit

Run one Mac host at a time.

Vamp Stream Host and Vamp Host share signaling and data ports. Stop one before starting the other; never expose those ports to the public internet.
