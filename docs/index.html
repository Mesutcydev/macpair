A mobile terminal with desktop habits

Everything stays in its place.

Vamp Terminal is designed around the moments that usually make an iPhone terminal frustrating: tiny controls, lost sessions, and tabs that secretly restart.

Live tabs, real shells

Each tab owns an independent PTY. Switching visibility never closes and reopens the process underneath.

Made for thumbs

Readable SwiftTerm output, scrollback, resize handling, paste, arrows, Ctrl, Esc, Tab, and a quick-key row.

Handoff, don’t restart

Attach tmux or screen from the app, or launch Claude Code, Codex CLI, Aider, and OpenCode in their own tabs.

No iOS app nearby?

Use Safari as your terminal workspace.

Vamp Host includes a terminal-only browser surface styled like a task chat. It runs on loopback and is exposed through Tailscale Serve, so the Mac never opens a public HTTP listener.

  • Pair with the six-digit code shown in Vamp Host.
  • Open up to eight concurrent browser CLI tabs.
  • Review commands with explicit Allow / Always allow / Deny cards.
  • Send and receive clipboard text from Safari.

Vamp CLI

Prepare a session before you pick up the phone.

The CLI is friendly to scripts and coding agents. Start a persistent tmux session on the host, then attach from a tab without restarting the process.

vamp ensureStart Vamp Host and wait until it is ready.
vamp status --jsonRead machine-friendly host state.
vamp terminal listList tmux and screen sessions.
vamp terminal start --session workCreate or resume a persistent shell.
vamp terminal attach workAttach the named session from a tab.
vamp terminal agent codex --session codexLaunch an agent-backed session.
vamp browser serveExpose the loopback Safari workspace through Tailscale.
vamp-terminal-host statusCheck the terminal-only macOS host.

Install without the App Store

Open source. Your Apple ID. Your device.

The project publishes an unsigned, device-only IPA. AltStore re-signs it with the Apple ID configured on your device.

Download

Get the latest Vamp Terminal IPA from Releases, or build it locally with Xcode.

dist/VampTerminal/*.ipa

Verify

Check the adjacent SHA-256 file before importing a build.

shasum -a 256 -c *.ipa.sha256

Sideload

In AltStore, choose + → Sideload IPA and let it sign the app.

AltStore → + → Sideload IPA

Pair

Enable Terminal Mode on Vamp Host, approve the pairing request, and connect.

Private by default

Less infrastructure. More control.

  • Terminal Mode is opt-in on the Mac and disabling it closes every active PTY.
  • Pairing is signed and requires visible host approval for a new device.
  • Remote Safari control binds to loopback and relies on your private Tailscale network.
  • Session IDs and terminal IDs route every tab independently.
  • No account backend, public port forwarding, or hosted relay is required.
