Peer-approved, always

Discovery over Bonjour on your LAN or Tailscale, signed peer identities, and a visible approval prompt for every new client. No account, no hosted relay.

Requirements

macOS 13+ for hosts and the Mac client. iOS / iPadOS 18+ for the mobile clients. Build from source needs Xcode 26+; the Linux host needs only Python 3.

Agent-friendly

Each host bundles the vamp CLI for status, pending, and fingerprint-verified pairing — scriptable and automation-ready. Ten agent launchers, tmux-backed.

Vamp

Open-source, local-first Mac remote desktop for macOS, iPhone, iPad, Safari, and Linux. Built on the macpair project. Not affiliated with Apple Inc.
