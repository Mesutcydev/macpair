01Browser

Safari is the client.

Eight tabs and ten agent launchers in the browser on the Mac host. Loopback 9475, Tailscale, or Cloudflare Access. No IPA. Pair with a six-digit code.

  1. 01
    Pair from the host

    Scan the QR on Vamp Host or type the six-digit code. It expires in ten minutes. The browser stays on your LAN or tailnet.

  2. 02
    Eight independent tabs

    Task chat and a real PTY in the same workspace. tmux and screen attach. Clipboard moves both ways.

  3. 03
    Ten agent launchers

    OpenCode, Claude, Codex, ChatGPT CLI, Grok, and the rest — same launchers as Vamp Terminal, without sideloading an IPA.
