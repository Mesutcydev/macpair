# Restyle browser-control UI + Vamp Terminal iOS app to the ZCode remote-sessions look

Reference: the attached ZCode screenshots (zcode.z.ai remote sessions) — light, flat, white card-based task chat. Both Vamp surfaces already replicate the ZCode *structure* (task-chat header, Chat/Terminal switch, approval cards, tab strip, composer); this is a visual restyle plus small ZCode-style status treatment. No protocol, trust, PTY, or WebSocket contract changes.

## Shared design language (from screenshots)
- Page `#FFFFFF`; cards white with 1px `#E4E4E7` hairline, radius 12–16; shadow only on floating elements (`0 1px 2px rgba(0,0,0,.05)`)
- Text `#18181B` / secondary `#71717A` / tertiary `#A1A1AA`; primary buttons near-black `#18181B` with white text
- Working status shown as elapsed text ("Working for 7m") with neutral dot; keep green=connected, amber=pairing, red=offline semantics
- System sans + mono for terminal (fonts unchanged); terminal surfaces stay dark, chrome is light
- Dark theme preserved as zinc equivalent (`#09090B` / `#18181B` / `#FAFAFA`), but **light becomes the default**

## A. Browser-control web UI — `Sources/HostApp/HostBrowserControlService.swift`
All changes inside the embedded `indexHTML` string; JS behavior, WS message types, element IDs, ARIA, and layout contracts (terminal mode, iOS keyboard handling) untouched.

1. Base layer (~1425–1434): `theme-color` → `#FFFFFF`; rewrite `:root` tokens to the light-first palette; flatten body background (remove radial/linear gradients).
2. Mid layers (`vampMoreStyle` ~1658–1771, script-3 layer ~3173–3538, `modeStyle` ~3542–3828): keep layout/behavior rules, strip gradient/glass visuals that would fight the flat look.
3. Rewrite the authoritative `browserControlDesign` layer (~3836–4549) as the ZCode layer: new `--bc-*` tokens, remove blur/backdrop-filter/grid/glow and the desktop floating-window chrome (flat full-width readable column); dark theme block recolored to zinc.
4. Component restyles: flat tab chips (active = dark fill), segmented-control mode switch, chat feed (gray meta, `#F4F4F5` user bubble, white stream cards, "Thought for…" collapsibles), flat task-plan and approval cards (numbered choice rows + black Confirm pill), white composer bar with black circular send, flat modals (pair / more / workspace) and agent grid, flat terminal keybar, flat Sessions dashboard.
5. Header status: replace the state pill with a ZCode-style elapsed working timer ("Working for Xm" while any tab/agent runs, else Connected/Pairing).
6. Appearance default: boot script default `'light'` (was `'system'`); keep the System/Light/Dark toggle.

## B. iOS app — Vamp Terminal target
1. `Sources/VampTerminal/VampTerminalGlassDesign.swift`: palette → adaptive zinc colors; surfaces from `.ultraThinMaterial` glass to flat cards (white/systemBackground + hairline, API names preserved so views inherit); backdrop drops wallpaper/grid/blurred circles → plain grouped background; provider accents and terminal colors unchanged.
2. `Sources/ClientiOS/VampTerminalWorkspaceView.swift`: flat header with "Working for Xm" status; flat tab chips; segmented-control Chat/Terminal switcher; flat chat feed/composer (black circular send, black Confirm buttons) and workspace sheets.
3. `Sources/ClientiOS/VampTerminalHomeView.swift`: flat host cards, black Connect buttons, flat error/progress cards.
4. `Sources/ClientiOS/VampTerminalPaneView.swift`: flat status bar + white keycap special-keys bar (terminal pane stays dark).
5. `Sources/ClientiOS/VampTerminalGuideView.swift`: flat cards.
6. `Sources/VampTerminal/VampTerminalApp.swift`: appearance default `"light"`.
