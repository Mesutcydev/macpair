## Variant: Product showcase

### Design stance
App-forward Apple-style page: real app screenshots in the hero with floating status chips, gradient accent, suite card with OS-coded platform pills, then a screenshot gallery.

### Key choices
- Layout: split hero (copy + stacked real screenshots with float chips) → 6-tile suite card with color-coded OS pills → 3-up screenshot gallery → feature duos
- Typography: display sans with gradient text accent
- Color: deep navy with blue→violet gradient (#6ea8ff → #a78bfa), teal accents
- Interaction: hover tilt on hero shots, release.json-driven downloads

### Trade-offs
- Strong at: shows the actual product, most "consumer polished", platform pills make app matrix obvious
- Weak at: depends on screenshot quality, gradient look is more generic SaaS

### Best for
- Presenting Vamp Suite as a finished product family; best first impression for non-CLI visitors.
