Vamp CLI

Prepare a session before you pick up the phone.

Script- and agent-friendly: start a persistent tmux session on the host, then attach from any tab without restarting.

vamp ensureStart the host, wait until ready
vamp status --jsonMachine-friendly host state
vamp terminal start --session workCreate or resume a persistent shell
vamp terminal attach workAttach the session from a tab
vamp terminal agent claude --session claudeLaunch Claude Code in a tmux tab
vamp browser serveExpose Safari workspace via Tailscale

Private by default

Less infrastructure. More control.

No account backend, no public port forwarding, no hosted relay. Your devices, your network, your approvals.

  • Terminal Mode is opt-in; disabling it closes every active PTY.
  • Pairing is signed and requires visible host approval for each new device.
  • Safari control accepts loopback and Tailscale traffic only — never public traffic.
  • Session and terminal IDs route every tab independently.
