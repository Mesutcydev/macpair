## Variant: Editorial hero

### Design stance
Big-type marketing hero with a single accent color, then one dominant "Get the suite" download card directly under the hero — downloads are the second thing you see, not buried mid-page.

### Key choices
- Layout: centered hero → full-width 6-tile suite card (3×2) → steps → features → safari → CLI → security
- Typography: huge display sans headline, mono eyebrows/pills
- Color: near-black with a single electric lime accent (#c8ff4d)
- Interaction: release.json-driven download buttons, theme toggle, copy buttons, mobile menu

### Trade-offs
- Strong at: first-impression impact, scannable download card, clear hierarchy
- Weak at: fewer real screenshots (CSS-drawn visuals instead), accent color is a big brand decision

### Best for
- Making thevamp.app feel like a confident product page; fastest path to "which file do I download?"
